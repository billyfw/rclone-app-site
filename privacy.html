bw-rclone privacy policy

bw-rclone is a personal OAuth client used only by its owner, with the owner's own Google account, to run rclone backup jobs on the owner's own computers.

  • The only data it touches is the owner's own Google Drive content, which the owner's rclone jobs copy to backup storage that the owner controls.
  • No data about anyone else is collected, stored, shared, sold or used for any other purpose.
  • Google sign-in credentials stay on the owner's own machines, in rclone's configuration file.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Questions go to the owner through the GitHub repository this page is published from.
